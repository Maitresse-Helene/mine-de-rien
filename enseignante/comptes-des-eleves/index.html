Comptes des élèves

Chaque élève a un login inventé (pas son prénom) et un code secret de 4 chiffres. Ses bons points sont gardés en ligne : il les retrouve sur tous les appareils.

Se connecter aux comptes

Les comptes sont sur internet : connectez-vous avec votre identifiant et votre mot de passe.

Première connexion : choisissez votre mot de passe (au moins 6 lettres ou chiffres), il remplacera l'ancien code de la maîtresse.

Les comptes

Créer un compte

Les élèves peuvent créer leur compte eux-mêmes en ouvrant l'appli (avec le code de la classe). Ici, vous pouvez en créer un pour eux, et ceux des élèves de 6e des devoirs faits.

Pour reporter les bons points gagnés dans les anciens liens : tapez le nombre à ajouter dans chaque jeu, puis « Enregistrer ». Pour vérifier une carte, tapez le login à la place du prénom.

Les bons points ajoutés portent la date d'hier et le « niveau 0 » : ils ne changent rien aux niveaux à réussir. « Retirer mes ajouts » n'efface que les bons points ajoutés ici.
