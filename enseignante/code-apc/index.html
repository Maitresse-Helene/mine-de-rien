Code APC d'une heure

Un code à écrire au tableau pour une séance : les élèves le tapent à la place du code de la classe.

····

  • Le code ouvre l'appli pendant une heure environ (jusqu'à l'heure indiquée). Ensuite il est refusé, et les tablettes qui l'ont utilisé redemandent le code, même si l'appli est restée ouverte.
  • Un nouveau code est disponible toutes les 10 minutes : si « Nouveau code » redonne le même, c'est normal.
  • Le code de la classe continue de marcher pour vos élèves. Un code APC ne peut pas être arrêté avant l'heure : en cas de besoin, demandez à Claude de les annuler tous.
