Vérifier une carte de bons points

Une carte complète vaut une récompense. Collez le message envoyé par la famille, ou recopiez le prénom, le numéro de la carte et son code : la page retrouve le jeu toute seule.

Le prénom, le numéro, le jeu et le code se remplissent tout seuls.

    Chaque carte valide s'inscrit ici, avec la date. Si la même carte revient, la page vous prévient. Cette liste reste sur cet appareil seulement.

    Chaque carte a un code de 4 caractères, propre au jeu, au prénom et au numéro de la carte. Majuscules, accents et espaces ne comptent pas, mais le prénom doit être écrit comme l'élève l'a tapé dans le jeu.
