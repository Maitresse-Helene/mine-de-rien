      Comment lire ces chiffres

      • Jeux ouverts : chaque fois qu'un jeu est ouvert (une page rechargée dans la minute ne compte qu'une fois).
      • Bons points gagnés : tous les bons points gagnés dans le jeu, par les élèves avec ou sans compte (pas ceux que vous ajoutez).
      • Élèves avec un compte : les comptes qui ont gagné au moins un bon point pendant la période. C'est le seul chiffre qui compte des élèves différents ; les comptes existent depuis le 14 novembre.
      • Appareils : chaque tablette, ordinateur ou téléphone compte une fois par jour, même si plusieurs élèves jouent dessus.
      • Vos passages ne comptent pas : ni quand vous êtes connectée, ni sur vos appareils où « Rester connectée » est coché. Sur iPhone, l'icône Crayonnade de l'écran d'accueil et Safari sont deux appareils à part : si vous jouez depuis l'un des deux sans y être connectée, ouvrez-y une fois votre Espace enseignante.
